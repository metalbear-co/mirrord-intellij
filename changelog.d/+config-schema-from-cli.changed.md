Changed the mirrord config JSON schema to come from the mirrord binary that the plugin uses. So the schema matches the version of mirrord that reads the config. The plugin fetches the schema from GitHub only when `mirrord print-schema` fails, for example because the binary is older than mirrord 3.257.0. When the plugin has no mirrord binary, config files have no schema until the plugin downloads one or you set a binary path.
